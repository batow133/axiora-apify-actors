## How to use

1. **Apify only:** Open an example above, copy it, replace the sample sources, and run once in your own account. Review pricing. Save the input as your own task, then [create an Apify schedule](https://docs.apify.com/platform/actors/running/schedules) if you want repeat runs.
2. **n8n:** Download one JSON and import it. In its HTTP Request node choose a Header Auth credential: name `Authorization`, value `Bearer <your Apify API token>`. Keep the token in credentials. Test once with the small sample. Each call requests a **US$0.25 maximum Actor charge** and a **90-second Actor timeout**; n8n and storage costs, if any, are separate. A timed-out request is not a reason to auto-retry a potentially billable run.
3. **Make it recurring:** Review the dataset and any source errors before connecting a destination. Change the source and output caps for your job. Enable the disabled daily Schedule Trigger and publish or activate the workflow only when ready. For repeated snapshots, deduplicate or compare across runs downstream; these recipes intentionally don't make scheduling decisions or send data to a third party.
